# Scripture Seek Bibles

Extra Bible versions for the [Scripture Seek](https://play.google.com/store/apps/details?id=com.tanucam.scriptureseek) app. The app downloads a version only when someone picks it, then keeps it on the phone.

Every text here is either in the public domain or released under an open license that allows sharing, including in apps. No personal data is stored here.

Files are in `v1/` as JSON: `[book][chapter][verse]` text, 66 books in the usual Protestant order, numbered like the King James Version.
